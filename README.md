# Баланс контента · fuchiji.dance

Приложение для планирования видео-контента: следит за балансом «личное ↔ экспертное», хранит идеи и сценарии по подтемам, считает снятые ролики и план на месяц.

**Открыть:** https://taoo1997-oss.github.io/content-balance/

## Как устроено
- Вход по аккаунту (email или телефон + пароль). Данные лежат в аккаунте и одинаковы на всех устройствах, где выполнен вход.
- Главный экран — кольцо «Личное / Экспертное», размер сегментов = доля идей. Кнопки `+ добавить личное` / `+ добавить экспертное` под соответствующими половинами.
- Клик по сегменту — зум внутрь категории: кольцо того же размера с подтемами из схемы «Ваш блог», у каждой в скобках — формат съёмки:
  - Личное: Ваши мысли (разговорный рилс), Ваша жизнь (сторис 3 р./нед.)
  - Экспертное: Польза (посты, карусели и рилс), Продукт (пост и истории), Результаты клиентов (рилс)
- Клик по подтеме — список идей: добавить, отметить снятым, редактировать, перенести, удалить (с отменой).
- Карточки справа: план на месяц с прогрессом и отдельный баланс по снятым роликам.
- Меню `⋯`: синхронизировать сейчас, установить на телефон, экспорт/импорт JSON, загрузка 20 хуков, очистка, выход.

## Установка на телефон (PWA)
Android/Chrome: меню `⋯` → «Установить на телефон» (или подсказка браузера «Добавить на главный экран»). iPhone: Safari → «Поделиться» → «На экран „Домой“». Открывается как отдельное приложение с иконкой, без адресной строки; работает и без сети — изменения уйдут на сервер, когда связь появится.

## Синхронизация
Сервер — Cloudflare Worker + D1, папка `../content-balance-backend` (адрес в `API_BASE` внутри `content-balance.html`). Клиент хранит копию в localStorage и после каждого изменения отправляет всё состояние на сервер. Если с другого устройства успели записать раньше, сервер отвечает 409 — клиент сливает обе версии (по идеям и подтемам, удаления через `tombstones`) и отправляет результат. Индикатор состояния — кнопка рядом с меню; нажатие обновляет вручную.

Файлы: `content-balance.html` (всё приложение), `manifest.webmanifest`, `sw.js`, `icons/`.
