# Баланс контента · fuchiji.dance

Одностраничное приложение для планирования видео-контента: следит за балансом «личное ↔ экспертное», хранит идеи и сценарии по подтемам, считает снятые ролики и план на месяц.

**Открыть:** https://taoo1997-oss.github.io/content-balance/

## Как устроено
- Главный экран — кольцо «Личное / Экспертное», размер сегментов = доля идей. Кнопки `+ добавить личное` / `+ добавить экспертное` под соответствующими половинами.
- Клик по сегменту — зум внутрь категории (подтемы из схемы «Ваш блог»: Ваши мысли, Ваша жизнь · Польза, Продукт, Результаты клиентов).
- Клик по подтеме — список идей: добавить, отметить снятым, редактировать, перенести, удалить (с отменой).
- Карточки справа: план на месяц с прогрессом и отдельный баланс по снятым роликам.
- Меню `⋯`: экспорт/импорт JSON (резервная копия), загрузка 20 хуков, очистка.

## Данные
Всё хранится в браузере (localStorage) на том устройстве, где открыт файл. Чтобы перенести на другое устройство — «Экспорт в JSON» → «Импорт из JSON».

Один файл, без зависимостей: `content-balance.html`.
