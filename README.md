# Баланс контента · fuchiji.dance

Приложение для планирования видео-контента: следит за балансом «личное ↔ экспертное», хранит идеи и сценарии по подтемам, считает снятые ролики и план на месяц.

**Открыть:** https://taoo1997-oss.github.io/content-balance/

## Как устроено
- Вход по аккаунту (email или телефон + пароль). Данные лежат в аккаунте и одинаковы на всех устройствах, где выполнен вход.
- Главный экран — кольцо «Личное / Экспертное», размер сегментов = доля идей. Кнопки `+ добавить личное` / `+ добавить экспертное` под соответствующими половинами.
- Клик по сегменту — зум внутрь категории: кольцо того же размера с подтемами из схемы «Ваш блог», у каждой в скобках — формат съёмки:
  - Личное: Ваши мысли (разговорный рилс), Ваша жизнь (сторис 3 р./нед.), Другое (танцы и прочее)
  - Экспертное: Польза (посты, карусели и рилс), Продукт (пост и истории), Результаты клиентов (рилс)
- Клик по подтеме — сценарии в трёх вкладках: **В очереди** → кнопка «Снято» → **Снято** → кнопка «Опубликовано» → **Опубликовано**. У опубликованного ролика можно вписать статистику из Instagram (просмотры, лайки, комментарии, репосты, пересылки, сохранения, подписалось); на вкладке «Опубликовано» — сводка по подтеме и **рейтинг роликов**: индекс 0–100 (доля от лучшего по просмотрам, ER и подпискам), короткие выводы (лидер, отрыв от типичного ролика, кто приносит подписчиков и вовлечённость) и место в рейтинге на каждой карточке.
- Кнопка **Опубликованные** в шапке — отчёт по всем вышедшим роликам: суммы и средние по метрикам, ER, баланс линий, общий рейтинг роликов по всем подтемам (тот же индекс 0–100, с выводами и подписью подтемы), таблица по подтемам, список всех роликов и «Скопировать отчёт для анализа» (текст для вставки в чат — с рейтингом каждого ролика).
- Вся статистика и анализ — только по опубликованным рилсам и постам; сторис («Ваша жизнь») не учитываются. План на месяц по-прежнему считает снятое.
- Карточки справа: план на месяц с прогрессом и баланс опубликованного.
- Кнопка **Идеи** в шапке — генератор идей без ИИ: 12 методик (случайный предмет по де Боно, чужой мир, кто → кому, механика × тема, против совета, наоборот, предмет в зале, возраст × место, твоё слово, ставка в цифре, пересборка своего ролика, вопрос из директа). Приложение задаёт вопрос с пропусками: в пропуск вписываешь своё, случайное слово стоит полупрозрачным примером (тап — взять, кубик — другой пример). Идею пишет человек (1–3 строки), кнопка «В очередь» кладёт её в выбранную подтему с пометкой методики (`idea.source`). «Подсказать угол» — по желанию: воркер спрашивает у Claude три угла для этой карточки (`POST /api/angle`, нужен секрет `ANTHROPIC_API_KEY`, лимит `AI_DAILY_LIMIT` в сутки).
- Меню `⋯`: синхронизировать сейчас, установить на телефон, экспорт/импорт JSON, очистка, выход.

## Установка на телефон (PWA)
Android/Chrome: меню `⋯` → «Установить на телефон» (или подсказка браузера «Добавить на главный экран»). iPhone: Safari → «Поделиться» → «На экран „Домой“». Открывается как отдельное приложение с иконкой, без адресной строки; работает и без сети — изменения уйдут на сервер, когда связь появится.

## Синхронизация
Сервер — Cloudflare Worker + D1, папка `../backend` (адрес в `API_BASE` внутри `content-balance.html`). Клиент хранит копию в localStorage и после каждого изменения отправляет всё состояние на сервер. Если с другого устройства успели записать раньше, сервер отвечает 409 — клиент сливает обе версии (по идеям и подтемам, удаления через `tombstones`) и отправляет результат. Индикатор состояния — кнопка рядом с меню; нажатие обновляет вручную.

Файлы: `content-balance.html` (всё приложение), `manifest.webmanifest`, `sw.js`, `icons/`.
